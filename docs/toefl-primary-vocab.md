# TOEFL Primary — Step 1, Book 1 — Vocabulary Extract

Source: `docs/Step1 TOEFL Book1.pdf` (Eduplanet / Nhân Trí Việt / NXB Tổng Hợp
TP.HCM), a scanned image-only PDF, 117 pages. Extracted by rendering each page
and reading the "Study the words" vocabulary box at the start of each unit.

The book has 4 vocabulary units (pages 14–93), followed by a Reading and
Listening Practice Test section (pages 95–117) with no further word lists.

This is beginner/elementary-level vocabulary (young learners), well below the
B2/C1 level used in Word Heist's core vaults. It has been added to the game as
a separate "Training" tier — see `docs/design.md` and `scripts/seed.ts`.
